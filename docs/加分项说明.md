# 实验 1A 加分项：TCP 流追踪与进程关联

对应课件第 14 页的两个加分方向：基于 IP + Port 的 TCP 流、某进程产生的 TCP 流。
本轮独立实现，不依赖 Wireshark，也不新增 Python 依赖。

## 如何使用

启动命令不变：

```bash
cd "/Users/roya/Desktop/security project"
.venv/bin/python -m lab1a_sniffer gui
```

窗口新增“TCP 流与进程”页：

1. 实时抓包或打开经典 PCAP 后，自动按 TCP 两端的 IP、端口建立双向连接索引。
2. 选择一个连接，查看 A/B 两端、双向包数和字节、观测状态、观测时长、握手观测时长。
3. 下方方向时序展示原包序号、相对时间、A→B / B→A、TCP 标志、Seq、Ack 和捕获载荷长度。
4. 双击时序行，会跳回“数据包”页，定位对应的原始包；协议树和原始字节仍可使用。
5. “仅看所选连接”会过滤数据包列表；协议显示条件仍共同生效。
6. 在数据包页选中 TCP/HTTP 包，点击“追踪所选包的 TCP 流”，可以直接打开对应连接。
7. 实时抓包时默认开启“实时关联本机进程”。快照匹配到的进程会出现在表格和进程下拉框中。
8. 选择进程可查看它在本次缓存中已关联的所有 TCP 流，再点击“查看该进程已关联 TCP 包”。
9. “取消连接过滤”恢复全部连接范围；协议筛选仍保留。

保存全部始终导出源缓存中的全部数据，不受协议、连接或进程过滤影响。
打开其他文件、清空、成功启动新抓包时，旧连接过滤、旧进程归属和旧时序均会重置。
打开失败、抓包启动失败仍保留原有数据和连接索引。

## 实现与原理

### TCP 连接索引

`flows.py` 从已经确认的 TCP 层读取原始字段，不解析摘要字符串来判断标志。
两端地址和端口规范化为无方向的连接键，再记录 A/B 方向。观察到初始 SYN 时以发起端为 A；
首包是 SYN+ACK 时可确定其相对端为 A；中途开始捕获时以首包发送端为 A，状态明确显示“中途捕获”。

- SYN 重传不重复建流。
- 同一四元组出现不同初始序列号的新 SYN，或已结束后的新 SYN，会建立新连接代次。
- 只有实际观察到相互对应的握手，才显示“已见三次握手”。
- FIN 关闭要观察到双向 FIN 及其确认；单个 FIN 仅显示“关闭中”；RST 显示“RST 结束”。
- 状态是抓包中的观测结论，不代表系统此刻仍保持连接。
- 未捕获到新 SYN 的四元组复用、缺包、乱序或异常握手可能无法准确分代；不是完整 TCP 状态机。

字节计数区分链路帧总字节与捕获到的 TCP 载荷，后者根据 IP 声明长度截取，排除 Ethernet 填充。
重传包仍是实际观察到的包，会重复计入统计；这些数值不是去重后的应用数据量。

索引最多保留 2048 条流、20000 个 TCP 包行号，每流最多保留 4 个进程持有者线索。
达到索引上限后显示未跟踪数量，原始包仍由原有缓存规则保留，不会声称全部包都已归组。
索引只引用行号，不复制包载荷。它与原有 128 MiB 保守解析缓存预算分别有界，
预算不等于整个进程内存 RSS。时序每页最多创建 200 行，实时界面最多每 500 ms 刷新连接列表。

### 进程关联

`processes.py` 通过系统 `/usr/sbin/lsof` 的字段输出采集当前用户可见的已连接 TCP 套接字。
只匹配完整的双方 IP 与端口，不根据监听端口推测所有者。回环连接的客户端和服务端都可能被记录。

查询前后通过 `/bin/ps` 核对 PID 的启动时间，并将启动时间加入进程身份，降低 PID 复用混淆。
快照按相近的抓包时间匹配近期活动的连接，界面记录快照时间。已确认的历史线索会保留到本轮数据清空。

- 每约 1 秒异步采样；只运行一个采样线程，单次命令超时 2 秒，关闭时取消并回收子进程。
- 输出上限 2 MiB（接收后检查）、8192 条套接字记录、2048 个进程，超过上限时放弃当次结果。
- 查询失败会提示，抓包和协议解析继续工作，不自动提权、不修改系统权限。
- 短连接可能在两次采样之间完成，因此“未关联”不是“没有进程”。
- 其他用户、受限进程、地址映射和代理转发可能无法匹配；代理出口包可能只能关联到代理进程。
- 这是套接字持有者的时间快照线索，不是内核逐包 PID 归属，也不能保证覆盖进程的全部网络活动。
- 停止抓包后保留本轮已观测线索，但不继续采样。
- 经典 PCAP 不包含进程信息；离线打开时不查询当前进程来猜测历史归属，保存再打开也不会保留 PID。

### 模块与线程

- `flows.py`：纯 Python TCP 分代、方向计数与行号索引，可独立测试。
- `processes.py`：系统命令、结构化快照、地址规范化、PID 启动时间。
- `gui_processes.py`：后台进程采样，Qt 定时器接收结果，退出时取消。
- `gui_models.py`：源缓存维护连接索引，代理组合协议与连接过滤。
- `gui_flows.py`：连接和进程列表、分页方向时序与跳转信号。
- `gui.py`：页签、过滤交互、会话生命周期和退出清理。

本轮未实现 TCP 字节流重组、HTTPS 解密、Wireshark 插件或 eBPF。流追踪与 TCP 重组是不同能力：
前者将同一连接的包归组并观察时序，后者进一步还原连续、去重的字节流。

## 验证

```bash
.venv/bin/python -m pytest --run-live --physical-interface en0
.venv/bin/python scripts/gui_flows_smoke.py
```

原生验收脚本创建独立服务端进程、同一客户端进程的两条连接和第三个进程的一条对照连接，
在 lo0 上真实抓包，检查握手、方向、进程区分、多流筛选、关闭、全量导出和离线重建。
