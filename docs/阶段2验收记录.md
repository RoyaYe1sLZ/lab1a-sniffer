
- 协议字段：Ethernet、VLAN、NULL、LOOP、原始 IP、IPv4、IPv6、TCP、UDP、ICMP、ICMPv6、HTTP。

- 回归：第一阶段的原生句柄、ABI、队列背压、停止、PCAP 写入与真实抓包测试继续通过。
- 独立核对：系统 tcpdump 识别五种参考包，地址、端口、TCP 序列号/确认号、TTL/跳数和 ICMP 字段符合预期。

## 真实流量解析

```bash
.venv/bin/python -m lab1a_sniffer selfcheck --analyze --physical-interface en0 --output-dir artifacts/stage2
```

开发侧首次验收：

| 流量 | 解析结果 | 检查 |
| --- | --- | --- |
| lo0 本地 HTTP | 请求与响应各一个，归类 HTTP，仍匹配 TCP/IPv4 | 请求/响应行、地址及随机端口正确 |
| lo0 本地 UDP | IPv4、IPv6 各一个 | 地址族、地址与端口正确 |
| en0 出站 UDP | 三个 Ethernet/IPv4/UDP 包 | 文档目的地址与指定端口正确 |
| lo0 IPv4 ping | ICMP 请求/响应 | Echo 类型与地址正确 |
| lo0 IPv6 ping | ICMPv6 请求/响应 | Echo 类型与地址正确 |

所有检查均为 true，三组解析 issue_count 均为 0，总结果 passed=true。
每次 TCP 结束报文数量可能不同，不以固定总包数作为通过条件。

完整字段和原始报文保存在 `artifacts/stage2/`，不会随 Git 提交。
另有可提交的人工合成样本 `samples/protocols.pcap`，与真实抓包明确区分。
