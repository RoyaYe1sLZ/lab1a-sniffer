# TCP 流与进程关联验收记录

验收日期：2026 年 11 月 12 日，macOS arm64 / Python 3.13 / Qt Cocoa / 系统 libpcap。

## 自动测试

`.venv/bin/python -m pytest -q --run-live --physical-interface en0`

179 项全部通过，约 8 秒。新增测试覆盖：

- 双向连接、IPv4/IPv6、ECN 标志伴随的三次握手、序列号回绕和带数据 SYN。
- SYN 重传、不同初始序列号的新连接、关闭后端口复用。
- 中途捕获、错误确认号/序列号、不完整握手不声称建立。
- FIN 双向确认、RST、截断载荷及 Ethernet 填充排除。
- 连接/包行号容量上限。
- lsof 字段、IPv6 地址、同一套接字多个持有者、忽略监听套接字。
- 时间和完整端点匹配，PID 扫描期间复用不归属，未知进程不猜测。
- 系统命令超时、取消、失败，采样线程与子进程回收。
- 当前进程真实 TCP 套接字快照。
- 连接与协议的组合过滤、同一进程多连接过滤、实时新增连接。
- 时序方向、分页、原始行定位、进程列表过滤与“追踪当前包”交互。
- 过滤状态下保存全部、离线重建、清空重置与关闭取消。

## Cocoa 原生窗口与真实进程

`.venv/bin/python scripts/gui_flows_smoke.py`

18 项检查通过。独立服务端、两个同进程客户端连接及独立对照客户端均为真实 TCP 套接字，
在 lo0 抓包。验证了所有连接握手、多流进程归组、对照进程不误归属、FIN 关闭、
时序定位、过滤导出全量、离线进程信息不伪造、窗口退出后没有工作线程遗留。

较大 PCAP 的自动等待使用局部 Qt 事件循环，避免连续 QTest.qWait 占据 GIL 而阻塞 Python 文件线程。
正常 Qt 事件循环中，5229 包的本机样本在约 0.4 秒内完成读取与界面替换；该数值仅为本机观察。
