# 合成协议样本

`protocols.pcap` 含五个独立、人工构造的 Ethernet 报文：

1. IPv4 / TCP / HTTP 请求：`192.0.2.1:12345 → 198.51.100.2:8080`。
2. IPv4 / TCP / HTTP 响应：`198.51.100.2:8080 → 192.0.2.1:12345`。
3. IPv6 / UDP：`[2001:db8::1]:12345 → [2001:db8::2]:54321`。
4. IPv4 / ICMP Echo Request：标识符 4660，序号 7。
5. IPv6 / ICMPv6 Echo Request：标识符 4660，序号 9。

这些地址来自文档地址段；文件由 `tests/packet_samples.py` 的字段构造函数生成，
不是实际用户流量，也不是包含握手/完整状态的 TCP 会话。固定时间戳仅用于测试。
五种样本已经用系统 tcpdump 交叉核对。

从项目根目录查看：

```bash
/usr/sbin/tcpdump -nn -S -vv -r samples/protocols.pcap
```

该文件可供后续 GUI 离线文件功能验收，当前阶段通过测试代码和 tcpdump 检查。
真实抓包验收的文件单独保存在被 Git 忽略的 `artifacts/stage2/`。
