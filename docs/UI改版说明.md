# UI 改版说明

2026 年 11 月 12 日，按用户确认的浅色预览方案落地到实际 PySide6 窗口。

## 界面变化

- 精简标题区，加入矢量网络标记，采用雾白底色、青绿色强调、统一圆角和细分隔线。
- 全局工具栏集中放置网络接口、BPF、抓包启停、打开和保存；两个工作页均可使用文件按钮。
- 启停操作共用一个固定位置，按会话状态显示开始或停止，保留原有启停逻辑。
- 统计条显示已捕获数量、当前可见数量、全部 TCP 流数和缓存原始字节量。
- 显示过滤改为协议按钮组；支持鼠标、Home/End、左右/上下方向键，协议组合匹配规则不变。
- 表格地址、时间等字段用等宽字体，协议显示为彩色标签，选中行使用青绿高亮。
- 协议树和深色字节面板保留可拖动分隔条、字段高亮、完整字节展开和原始行映射。
- TCP 流页统一工具栏、表格和详情区域样式；自动滚动、进程采样采用开关外观。
- 主题集中在 `gui_theme.py`，可复用视觉组件集中在 `gui_widgets.py`，没有新增依赖。

数据量指缓存包原始字节总和，包含包头，不包含 PCAP 文件记录头和 Python 对象开销；
底栏继续显示对象缓存预算及可获得的丢包信息。TCP 流数是全部缓存的连接索引数量，
不随数据包显示过滤改变。未捕获、未获得的统计显示零或原有的未知标记，不生成模拟运行数据。

## 验证

- 全套测试（包含真实 en0/lo0 行为）：181 项通过，约 8 秒。
- 协议按钮新增点击和键盘验收，确认过滤、选中包、统计条保持一致。
- 原生实时抓包验收 14 项通过；原生文件/过滤验收 22 项通过；TCP 流与进程验收 18 项通过。
- 最终下拉框绘制调整后，39 项 GUI 相关测试全部通过。
- Cocoa 实际窗口在 980 和 1320 像素宽度下检查工具栏、协议选择和文件操作位置；无控件越界。
- 使用本机实际抓包核对连接筛选、字段高亮、流选择和安全退出。
